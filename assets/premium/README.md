# Материалы для Premium-версии

В эту папку нужно будет положить две финальные фотографии. Предпочтительный формат — WebP, цветовое пространство sRGB.

## 1. `therapist-office.webp`

- Портрет терапевта внутри кабинета.
- Квадратный исходник или широкий исходник с запасом для круглой обрезки 1:1.
- Рекомендуемый размер: не меньше 2000 × 2000 px.
- В кадре должен читаться интерьер, но главным остаётся человек. Важные детали нельзя располагать у углов изображения — после круглой обрезки они исчезнут.

## 2. `office-wide.webp`

- Фотография кабинета с центральной композицией для круглой обрезки 1:1.
- Рекомендуемый размер: не меньше 2200 × 2200 px.
- Дневной свет, кресло или зона разговора, натуральные фактуры и несколько деталей пространства. Главный объект должен находиться ближе к центру.

Не нужно заранее обрезать исходники слишком плотно: финальное кадрирование лучше сделать уже внутри макета после проверки desktop и mobile.
