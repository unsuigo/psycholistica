# Материалы для Premium-версии

В эту папку нужно будет положить три финальные фотографии. Предпочтительный формат — WebP, цветовое пространство sRGB.

## 1. `hero-portrait.webp`

- Новый основной портрет Магдалены.
- Вертикальный кадр 4:5.
- Рекомендуемый размер: не меньше 1600 × 2000 px.
- Естественный мягкий свет, спокойный нейтральный фон, взгляд в камеру или немного в сторону.

## 2. `therapist-office.webp`

- Портрет терапевта внутри кабинета.
- Вертикальный кадр 3:4.
- Рекомендуемый размер: не меньше 1500 × 2000 px.
- В кадре должен читаться интерьер, но главным остаётся человек.

## 3. `office-wide.webp`

- Широкая фотография кабинета.
- Горизонтальный кадр 16:10.
- Рекомендуемый размер: не меньше 2400 × 1500 px.
- Дневной свет, кресло или зона разговора, натуральные фактуры и несколько деталей пространства.

Не нужно заранее обрезать исходники слишком плотно: финальное кадрирование лучше сделать уже внутри макета после проверки desktop и mobile.
